# React Native Slide Ruler

A React Native interaction experiment that implements a horizontally sliding measurement ruler.

## Project goal

Practice gesture-driven mobile interfaces, value interpolation and visual feedback through a focused UI component.

## Features

- Horizontally scrollable ruler
- Selected-value feedback
- Mobile-first interaction
- Expo development workflow

## Technologies

- **TypeScript**
- **React Native**
- **Expo**

## What I learned

- Building a precision input control for touch screens
- Mapping scroll position to a numeric value
- Rendering repeated ruler markers efficiently
- Following and adapting a UI implementation tutorial

## Running locally

```bash
npm install
npm start
```

## Project status

This is a learning and experimentation repository. It documents the concepts practiced at the time and is not presented as a production-ready application.
